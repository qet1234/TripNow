# 항공권·탑승권 OCR 개인정보 보호 설계

## 처리 범위

TripNow는 사용자가 직접 선택한 종이 항공권 또는 탑승권 이미지에서 출국·귀국 일정에 필요한 최소 정보만 읽습니다.

저장 대상:

- 항공편 번호
- 출발일·시간
- 출발 공항·도착 공항에서 파생한 도시
- 터미널 번호

저장하지 않는 대상:

- 원본 항공권 이미지
- 전체 OCR 전문
- 탑승객 이름
- 예약번호·항공권 번호
- 좌석번호와 바코드 원문

## 데이터 흐름

1. 사용자가 Android 시스템 파일 선택창에서 항공권 사진 한 장을 직접 선택합니다.
2. 기존 TripNow 온디바이스 ML Kit OCR 모듈이 텍스트를 읽습니다.
3. 항공편·날짜·공항 정보를 파싱해 편집 화면에 채웁니다.
4. 사용자가 결과를 확인·수정한 뒤 저장합니다.
5. 저장된 최소 일정만 기기 내부 공항 일정 저장소에 보관합니다.

OCR은 항공권의 계획된 출국·귀국 방향을 판별하는 기능이며, 실제 탑승 또는 항공기 도착을 확인하는 기능은 아닙니다. 실제 운항 상태는 별도 항공편 API 연동이 필요합니다.

출시 전에는 개인정보처리방침과 Google Play 데이터 안전 섹션에서 사용 중인 ML Kit SDK의 진단·성능·사용량 지표 처리 여부를 앱 전체 기준으로 다시 확인해야 합니다.
