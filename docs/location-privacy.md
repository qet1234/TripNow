# TripNow 위치 처리 원칙

TripNow 1차 버전은 로그인 없이 사용합니다.

## 위치 권한 사용 목적

위치 권한은 사용자가 일본에 도착했는지 **단말 내부에서 확인**하는 용도로만 사용합니다.

- 현재 좌표를 Supabase에 전송하지 않음
- 현재 좌표를 TripNow API에 전송하지 않음
- 현재 좌표를 로그에 기록하지 않음
- 위치 이력을 저장하지 않음
- 백그라운드 위치 권한을 사용하지 않음
- 위치 공유 기능을 제공하지 않음

일본 도착 여부 확인 후 위도/경도 값은 함수 밖으로 반환하지 않습니다.

## 주변 검색

관광지, 음식점, 카페, 경찰서, 병원 검색은 사용자 GPS가 아니라 사용자가 선택한 지역의 고정 중심 좌표를 기준으로 합니다.

예:

```text
사용자 선택: 도쿄 · 시부야
        ↓
TripNow 고정 지역 중심좌표
        ↓
Places / 날씨 검색
```

고정 지역 중심좌표는 개인위치정보가 아닙니다.

## 길찾기

TripNow은 출발지 GPS를 직접 계산하거나 서버에 전달하지 않습니다.

```text
TripNow
  ↓ 목적지만 전달
Google Maps
  ↓
현재 위치 → 목적지 경로 처리
```

현재 위치 기반 내비게이션은 외부 Google Maps가 처리합니다.

## 국내 사용

한국 등 일본 외 지역에서는 기본적으로 `미리보기 모드`를 사용합니다.

사용자는 도쿄, 오사카, 후쿠오카 등 지역을 직접 선택해 날씨·장소·환율·면세·회화 정보를 미리 볼 수 있습니다.

## 주의

이 설계는 위치정보 최소화를 위한 기술 구조입니다. 위치기반서비스사업 신고 여부에 대한 최종 법적 판단은 실제 출시 기능과 운영 방식에 따라 별도 확인합니다.
